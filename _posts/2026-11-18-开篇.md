欢迎来到我的个人博客。这是第一篇文章，简单记录一下这个站点是做什么的，以及接下来会写些什么。

## 为什么开这个博客

平时做项目时，总会遇到一些值得记录的东西：一个反复踩过的坑、一段查了很久资料才搞懂的原理、一次实验结果的意外反转。这些结论如果不写下来，过段时间就忘了。这个博客就是用来沉淀这些内容的——**写给未来的自己，也顺便分享给可能遇到同样问题的人**。

## 这里会写什么

大致分为几个方向：

- **工程实践**：工业软件、数据处理、报告生成等实际项目中的设计与踩坑记录。
- **机器学习与视觉**：模型训练、评估、数据增强等实验过程与结论复盘。
- **工具与方法**：提升效率的小技巧、环境配置、脚本片段。
- **随笔**：偶尔的总结与思考。

## 关于站点

本站基于 [al-folio](https://github.com/alshedivat/al-folio) 模板搭建，使用 Jekyll + GitHub Pages，源码托管在 GitHub 上。每次提交到 `main` 分支后，会自动构建并发布，无需手动维护服务器。

- 站点地址：[https://zoush99.github.io](https://zoush99.github.io)
- 技术栈：Jekyll · Markdown · GitHub Pages

## 更新计划

不追求固定频率，有值得写的东西就更新。如果你发现文中有错误，欢迎通过留言或邮件指出。

那就从这里开始吧。
